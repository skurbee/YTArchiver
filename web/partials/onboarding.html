Welcome to YTArchiver

We'll choose your archive folder, traffic limits, and download tools.

  • Choose where your archive lives
  • Install the download tools (yt-dlp + ffmpeg)
  • Optionally set up AI transcription (Whisper)

Pick an archive folder

YTArchiver saves each subscribed channel as a subfolder here. Choose an empty folder (or an existing YTArchiver archive). You can change it later in Settings.

Choose a traffic safety level

YTArchiver stays deliberately low and slow to protect your YouTube session. You can change this later in Settings.

Install dependencies

Download tools required
AI transcription optional
Sets up Python 3.11 + faster-whisper + torch. Large download (~3 GB with GPU acceleration) — it runs in the background and you can keep using the app. Safe to skip and set up later; downloading videos works without it.
YouTube sign-in recommended
YTArchiver signs into YouTube using your Firefox cookies — needed for age-restricted, members-only, or private videos, and to avoid “confirm you're not a bot” blocks. Chrome and other Chromium browsers aren't supported (their cookie storage is encrypted and can't be read). Sign into YouTube in Firefox, then click Re-check below.

You're all set

YTArchiver is ready. Use Browse > Channels to manage subscriptions or add a channel, or paste a video URL on the Download tab to grab a single video.
